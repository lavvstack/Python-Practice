# Python Programming Assignment

## Overview
This project contains four Python programs demonstrating the use of fundamental Python data structures through practical exercises.

## Tasks Completed

### Task 1 – Product Collections
- Creating and manipulating lists and tuples
- Accessing elements using indexing
- Adding new elements
- Converting tuples into lists and vice versa

### Task 2 – Categories
- Creating sets from lists
- Adding elements to sets
- Understanding duplicate removal
- Checking membership
- Counting unique elements

### Task 3 – Product Pricing
- Creating dictionaries
- Adding and updating key-value pairs
- Removing elements
- Handling products that do not exist
- Calculating average product prices

### Task 4 – Combined Data Structures
- Working with lists of tuples
- Creating dictionaries using loops
- Grouping products by category
- Finding the category with the maximum number of products

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
Run each Python file using the terminal:

```bash
python task1.py
python task2.py
python task3.py
python task4.py
```
