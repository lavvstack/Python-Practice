# Assignment 2 – Python: Control Flow (Conditionals & Loops)

## Overview
This assignment focuses on understanding and implementing Python control flow concepts using conditional statements and loops. It includes practical examples of order processing, discount calculations, and menu-driven programs.

## Tasks Completed

### Task 1: Discount Rules (if / elif / else)
- Takes the order amount as input from the user.
- Applies discounts based on the order amount.
- Calculates and displays the discount and final payable amount.
- Handles invalid inputs using `try-except`.

### Task 2: Process Multiple Orders (for loop)
- Processes multiple orders stored in a list.
- Applies discounts to each order based on predefined conditions.
- Calculates the total revenue after discounts.
- Counts the number of discounted orders.

### Task 3: User Menu (while loop + break/continue)
- Provides a menu-driven interface.
- Allows users to add order amounts.
- Displays all orders and their total revenue.
- Uses `while`, `break`, and `continue` for program control.

### Task 5: Loop Control with Conditions (break & continue)
- Processes daily sales data stored in a list.
- Skips days with zero sales using `continue`.
- Stops processing when corrupted data (`-1`) is encountered using `break`.
- Calculates the final total sales.

## Concepts Used
- Conditional Statements (`if`, `elif`, `else`)
- `for` and `while` loops
- `break` and `continue`
- Lists
- User Input (`input()`)
- Exception Handling (`try-except`)
- Basic Arithmetic Operations
