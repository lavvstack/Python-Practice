# Assignment 3 – Python Functions

## Overview
This assignment focuses on Python functions and their variations. It covers user-defined functions, recursive functions, lambda functions, `map()`, and `filter()` through simple billing and utility automation tasks.

## Topics Covered
- User-defined functions
- Default arguments
- Recursive functions
- Lambda functions
- `map()` function
- `filter()` function
- Combining functions
- Menu-driven programs using functions

## Tasks

### Task 1 – Price After Discount
Created a function `apply_discount()` to calculate the final price after applying a discount. It uses a default discount of 5% and ensures the discount does not exceed 60%.

### Task 2 – Factorial Utility
Implemented a recursive function `factorial()` to calculate the factorial of a number. It handles zero, one, and negative numbers.

### Task 3 – GST Calculator
Created a lambda function to calculate the price after adding 18% GST.

### Task 4 – Apply GST Using map()
Used `map()` with a lambda function to apply 18% GST to a list of prices and generate a new list.

### Task 5 – Filter Expensive Products
Used `filter()` to separate product prices into two lists:
- Prices greater than ₹500
- Prices less than or equal to ₹500

### Task 6 – Combined Utility Function
Created `process_prices()` using `map()` and `filter()` to apply a 10% discount and filter prices greater than ₹300.

### Task 7 – Menu Using Functions
Developed a menu-driven program with the following operations:
1. Add a price.
2. Display the average price.
3. Display the highest price.
4. Exit the program.
